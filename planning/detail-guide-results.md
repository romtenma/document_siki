- ワークスペース0を共通とするレイアウト継承、独自配置、共通配置のコピー。

- 別ウィンドウの通常・動画上・流し表示。旧実況コメント入力欄を案内しない。
- アップロード先の選択、あぷ小＠ふたばの送信処理・履歴。表示形式と送信可能形式を区別。
- AI接続設定、送信範囲・除外、要約・質問。未提供の「Sikiへの質問と設定変更」を利用できる機能として説明しない。
- Sync2chの同期対象と起動・終了・サスペンド・レジュームの自動実行設定。
- 起動オプション、保存先の親ディレクトリ、ポータブル判定とオプションファイルの条件。

根拠と残る確認は[確認記録](verification/detail-guide.md)にまとめています。外部サービスへの投稿、画像送信、AIリクエスト、同期は実行していません。

## 参照資料の生成

`scripts/import-source-reference.mjs` は、アプリのチェックアウトにあるBabelパーサーを使い、ソースの構文木から許可したリテラルの表示メタデータだけを読み取ります。アプリのモジュールを実行しません。公開ビルド・CIにはアプリ側のチェックアウトやパーサーは不要です。

```sh
node scripts/import-source-reference.mjs ../Siki
```

更新後はMarkdownの差分を人が確認してから通常の検査を行います。抽出した元ファイルのSHA-256、版、件数を [reference-snapshot.json](reference-snapshot.json) に記録します。作業ツリーを読むため、未コミットの変更も反映されます。

| 出力 | 今回の件数・制約 |
| --- | --- |
| コマンド一覧 | 812件。基本表示名・ID・明示された引数個数・動的定義の有無。実行可能性、引数の型・順序、実行時の追加コマンドは保証しない |
| 設定リファレンス | 428項目。画面定義の説明・ID・形式・明示された初期値。継承する設定を通常の分類へ統合。非表示条件付き・独立エディターの内部項目等は除外 |

`formDefault` を実際の有効な既定値や保存済み値として扱わないことを本文にも明記しました。式で決まる値は評価せず、説明で画面確認へ案内しています。
