# 高優先度の図・画面画像の制作・確認記録

日付：2026-11-03。対象版：1.0.0。撮影・操作確認版：Siki-dev 0.99.25。環境：Windows。状態：準備版での掲載画像を追加、正式版の確認待ち。

## 撮影条件

通常利用と別の作業用プロファイルを、このリポジトリのGit管理対象外である `verification-output/` 配下に用意しました。既存のSiki開発版を `--datapath` と固有の `--nameplace` で起動し、生成された保存先と版を確認しました。撮影後は作業用ウィンドウを閉じました。

Windows computer-useの `@oai/sky` で実画面を操作・撮影しました。掲載画像は撮影範囲の切り出しのみです。基準は既存画像と同じ暗いテーマ1種類で、別テーマとの比較はしていません。小さな画面で文字を確認できるよう、各画面画像には原寸画像へのリンクを付けました。

文章はローカル板に架空のサンプルを作成しました。確認画面の投稿先は `siki://wall/local/` でした。外部掲示板への投稿・画像アップロードは実行していません。
