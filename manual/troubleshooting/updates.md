# 更新できない

新版を見つける、ファイルを取得する、インストールする、という段階を分けて確認します。配布形式により、アプリ内で行える範囲は異なります。

## 新版が表示されない {#check}

現在の版、β版を受信する設定、通信状態を確認します。お使いのOS・CPU・配布形式に合う新版が用意されている必要があります。

起動時の確認を無効にしている場合でも、更新の確認を手動で開けます。バージョンだけでなく、配布ファイルの対応も[公式のReleaseページ](https://github.com/romtenma/siki-release/releases)で確認します。

## ダウンロード・反映に失敗した {#download}

更新画面のエラーを確認し、通信や空き容量など該当する原因を調べて再試行します。更新準備ができても、「Sikiを終了して更新」を選ぶまでは明示的なインストールを開始しません。

macOS DMG、Windowsポータブル、Linux deb / rpmは、案内された同じ形式の配布物を使って手動更新します。

## 形式を確認する {#distribution}

[インストールと更新](../getting-started/install.md#updates)で更新方式を確認してください。旧版の `app.asar` 単体置換を、新しい配布一式の更新手順として使いません。

別の配布形式へ切り替える場合は、[バックアップ](backup.md)と[現在の保存先](../reference/data-locations.md)を先に確認します。
