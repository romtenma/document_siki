# 書き込めない

閲覧と投稿では必要な条件が異なります。エラー内容と投稿先を確認し、どの段階で止まっているかを調べます。

## ボタンが無効になっている {#disabled}

送信中や取得中、投稿後の待機中では、書き込みボタンを押せない場合があります。「次の書き込みまであと○秒」がある場合は待機時間を確認します。

サイト・板別の待機設定が0秒でも、サイト側の投稿間隔や規制は残ります。Sikiの待機設定を、サイト規制の解除として扱わないでください。

## エラーが表示された {#error}

| 内容 | 確認すること |
| --- | --- |
| 認証やCookieに関する案内 | そのサイトで必要な認証と、Sikiの対応状況 |
| 投稿間隔・規制・文字数など | サイトのルールと入力内容 |
| 接続失敗・タイムアウト | [通信・取得の確認](network.md) |
| 作成できない・投稿機能がない | [対応サイトと制限](../reference/supported-sites.md) |

認証が必要な場合は、そのサイトやSikiの画面に表示される案内に従います。別のサイト向けの設定や古い回避策を一律に適用せず、対象サイトの条件を確認します。

## 送れたか分からない {#uncertain}

同じ内容を続けて送信する前に、スレッドを更新して投稿があるか確認します。本文は控えを残してから画面を閉じます。

[書き込みの基本](../basics/posting.md)も確認してください。
