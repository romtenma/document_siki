# 困ったとき

まず、どの操作で何が起きたかを確認します。表示されたエラーがある場合は、その内容を控えてから、症状に合うページへ進みます。

## 症状から探す {#symptoms}

| 症状 | 確認するページ |
| --- | --- |
| 画面や配置が変わった、設定が反映されない | [表示・配置・動作](display.md) |
| 板やスレッドを読み込めない | [通信・取得](network.md) |
| 投稿できない、書き込みボタンが押せない | [書き込み](posting.md) |
| 画像や動画が開かない | [画像・動画](media.md) |
| 新版へ更新できない | [更新](updates.md) |
| 設定やデータを戻したい | [バックアップと復元](backup.md) |

## 原因を絞る {#narrow-down}

1. 問題が特定のサイト・板・スレッドだけで起きるか確認します。
2. エラー、実行した操作、現在のバージョンを確認します。
3. 表示の問題なら、フィルターや個別設定など、関連する項目を確認します。
4. 更新や再起動が必要な場合は、入力中の内容と保存状態を確認してから行います。

データを消す操作を最初の対処にはしません。ログ、設定、キャッシュは役割が異なります。削除・初期化が必要と判断した場合も、対象とバックアップを確認します。

## 問い合わせるとき {#report}

OS、Sikiのバージョンと配布形式、対象サイト、再現する操作、エラー内容を整理します。画面画像やログを共有する場合は、認証情報や公開したくない内容が入っていないか確認してください。

問い合わせ先は[公式の案内](https://sikiapp.net/contact/)を参照してください。
