# バックアップと復元

設定を戻すためのバックアップと、ログ・画像も含めて環境を保管するコピーは、対象が異なります。更新前や環境の移行前に、必要なデータを確認します。

## 何を残すか選ぶ {#scope}

| 方法 | 主な対象 |
| --- | --- |
| 設定のバックアップ | 設定ファイルや管理データ、テーマ・プラグイン等をZIPへ保存する |
| プロファイルと外部保存先のコピー | 閲覧ログ・画像なども含め、必要な保存データを保管する |

設定のZIPを作っただけで、すべての閲覧ログ・画像を保管したとは限りません。ログや画像を別の場所に保存している場合は、その保存先も対象にします。

## 設定をZIPに保存する {#settings-backup}

メインメニューの「設定のバックアップ」、または設定の「システム」→「バックアップ」から手動バックアップを実行します。完了後は保存先にZIPがあることを確認します。

自動バックアップの有効・無効、間隔、保持数も同じ分類で確認できます。通常のバックアップ保存先は[ファイルの場所](../reference/data-locations.md#find-location)から確認します。

## 環境全体を保管する {#full-copy}

1. プロファイル、ログ、画像、手動保存先など、現在の保存先を確認します。
2. Sikiを終了します。
3. プロファイルと、外部に分けた必要な保存先を別の場所へコピーします。
4. どのバージョン・環境の控えかを記録します。

使用中のデータベースを含むため、アプリを終了した状態でコピーします。旧版へ戻す可能性がある場合は、更新前の控えを上書きせず残します。

## 復元前に確認する {#restore}

現在のデータも別に保管してから、Sikiを終了して復元します。同じ環境・同じ版のプロファイル全体の控えを戻す場合と、設定ZIPから一部を戻す場合は手順を分けます。異なる版のデータを混在させないよう確認してください。

設定ZIP内の `config.original.js` は元の `config.js` の控えです。ZIPを展開するだけで、現在の保存先や設定がすべて自動復元されるわけではありません。設定ファイルを戻すときは、環境ごとの保存先も確認します。

別のPC・OSへの移行や、旧版への巻き戻しは条件が異なります。復元対象が不明な場合は、データを保管したうえで[問い合わせ](index.md#report)に必要な情報を整理してください。
