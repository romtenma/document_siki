# 画像URLの補正

`ImageViewURLReplace.dat` は、レス中でURLとして認識したリンクの扱いを補正する設定です。ページURLから画像URLを得たり、画像・動画・リンクとしての表示方法を指定したりするために使います。

::: info 1.0.0向けの確認中の項目
他の専用ブラウザと完全に同じ動作は保証されません。特に正規表現の照合・抽出・置換は、現在の実装と旧資料で再確認が必要なため、既存ルールの移植結果を個別に検証してください。
:::

## 保存先と編集 {#file}

プロファイルの `compatible/ImageViewURLReplace.dat` を編集します。自動生成されたファイルの説明も確認してください。Sikiを終了して元のファイルを控え、一つのルールだけ変更して再起動し、対象URLの表示を試します。

画像自体の取得失敗、NG、ぼかしの問題は[画像・動画が表示されない](../troubleshooting/media.md)の手順も確認します。URL補正ですべての表示失敗を直せるわけではありません。

## 一行の書式 {#format}

```text
URLの照合パターン【TAB】置換URL【TAB】参照URL【TAB】動作モード【TAB】抽出パターン
```

区切りには実際のタブ文字、または文字列 `【TAB】` を使えます。行頭の `//` や `;` はコメントです。前後へ不用意に空白を加えず、空の列を残す場合も区切りを保ちます。

| 列 | 役割 |
| --- | --- |
| 1 | 対象のURLを照合する指定 |
| 2 | 補正後のURLや表示に使う文字列 |
| 3 | 抽出時に取得するURL、参照元の指定など |
| 4 | 画像・リンク・カードなどの扱い |
| 5 | 取得した本文から抽出する指定。指定した場合は抽出処理の対象 |

## 主なモード {#modes}

| モード | 主な用途 |
| --- | --- |
| `$VIEWER` | 画像ビューア向けのURL |
| `$EXTRACT` | ページ取得結果から画像URLを抽出 |
| `$OGP` | ページのOGP情報を使ったカード表示 |
| `$TWITTER` | 対応する投稿の埋め込み |
| `$MOVIE` | 動画として扱う |
| `$LINK` | リンクとして扱う |
| `$TEXT` | テキストとして扱う |

置換欄の `$1` などと、取得したページから抽出する `$EXTRACT1` などは対象が異なります。旧資料のサンプルに書かれたURLが現在も有効とは限らないため、補正前後のURLと対象ページを確認します。

複数のルールが同じURLへ一致する場合もあるため、順序を含めて確認します。期待どおりにならなければ、控えたファイルへ戻して切り分けてください。
