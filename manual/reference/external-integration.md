# 外部ツールとの連携

外部連携は、URLを開く、プログラムを起動する、書き込み欄とファイルを同期するなど、目的によって入口が異なります。

## URLを外部ブラウザで開く {#browser}

リンクのメニューから外部ブラウザで開く操作を選びます。Siki内に表示する場合は[ブラウザビュー](../features/browser.md)を使います。

HTTP・HTTPS以外のプロトコルやファイルを開く場合は、確認が表示されることがあります。対象のURLと、起動するアプリを確認してください。

## 外部プログラムを実行する {#execute}

[ユーザーコマンド](../customization/user-commands.md)で `core:execute` を利用できます。実行ファイルの指定と、渡す引数を分けて設定します。実行のたびに表示される確認で、プログラムと引数を確かめます。

Windowsでは、直接実行するプログラムへ引数を渡す方式と、明示的にシェルを起動する方式を区別してください。`&` や `|` などを書いても、直接実行の引数が自動でシェルの処理になるわけではありません。バッチファイルには追加の制限もあるため、引用符や `%` を含む引数を無条件に持ち込まないでください。

引数へ選択文字やURLを渡すときは、空白・日本語・引用符を含む内容でも意図した値になるか確認します。コマンドによって対象となるレスやタブが必要です。

## 書き込み欄をファイルと同期する {#post-file}

書き込み欄には、外部エディターなどと連携するための次の操作があります。

| コマンド名 | 用途 |
| --- | --- |
| 書き込み欄と同期するファイル選択 | 同期先ファイルを指定 |
| 同期ファイルを開く | 指定したファイルを開く |
| 同期ファイルクリア | 同期先の指定を解除 |

使い始める前に本文の控えを残し、ファイルを編集した結果がどの書き込み欄へ反映されるかを確認します。外部エディターへの保存と、掲示板への送信は別の操作です。投稿前にSiki側の本文を確認します。

## その他の連携 {#other}

読み上げなどは[プラグイン](../customization/plugins.md)、画像の送信は[アップロード](../features/uploads.md)、AIは[AIサイドパネル](../features/ai.md)、お気に入りスレッドの連携は[同期](../features/sync.md)を参照してください。サービスごとのキーやログインは、それぞれの設定で管理します。
