# 保存先とファイル構成

Sikiは、設定、閲覧ログ、画像、履歴などを保存します。通常の保存先、ポータブルモード、起動時に別の保存先を指定した場合では場所が異なります。

## 現在の保存先を確認する {#find-location}

- Welcomeページの「Sikiの使うファイル」で、実際のデータ保存先と実行ファイルの場所を確認できます。
- 設定の「システム」→「ファイルの場所」で、ログ、画像、プラグイン、バックアップなどの保存先を確認します。
- メインメニューなどのフォルダーを開く操作も、対象を確認して使います。

インストール先とデータ保存先は同じとは限りません。OSごとの既定パスだけを頼りにせず、現在の環境で表示される場所を確認してください。

## 主なデータの役割 {#files}

| ファイル・領域 | 役割 |
| --- | --- |
| `config.js` | アプリの設定や保存先など |
| `user.js` | ユーザーの動作設定 |
| `components/` | キーボードやマウス、アクションなどの設定 |
| `site/` | サイト・板などに関する設定 |
| `theme/` | テーマやその画像など |
| `plugins/` | プラグイン |
| `log/` | 板・スレッドのログ。保存先を変更できる |
| `img/` | 取得した画像など。保存先を変更できる |
| `backup/` | 設定バックアップのZIP。保存先を変更できる |
| `bookmark.sqlite` | 新しい形式のお気に入り管理データ |
| その他のDB・保存ファイル | ローカル板、履歴、NG・ミュート、タブや既読状態など |

旧版から移行したファイルが残る場合もあります。名前が似ていることだけで現在使うデータを判断せず、旧版のファイル一覧を新しい版へ一律に当てはめないでください。

## ポータブルモード {#portable}

Windowsのポータブル一式で、実行ファイルと同じ場所に `data` がある構成では、その中へデータを保存します。別の保存先を明示した場合やインストーラー版とは条件が異なるため、起動後の保存先を確認します。

## ファイルを扱う前に {#before-copy}

プロファイルをコピー・復元するときはSikiを終了します。SQLiteなどのデータベースを含むため、使用中のファイルを一部だけ取り出す方法で、環境全体の控えを作ったとは限りません。

ログや画像を外部保存している場合は、その場所も確認します。[バックアップと復元](../troubleshooting/backup.md)へ進んでください。ファイルを直接編集する場合は、元の控えと保存形式を確認します。
