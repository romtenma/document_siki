# 起動オプション・ポータブルモード

起動オプションで保存先やアプリ名を指定すると、通常の環境と分けて起動できます。新しい指定で起動する前にSikiを終了し、起動後は実際の保存先を確認します。

## 主なオプション {#options}

| オプション | 意味 |
| --- | --- |
| `--nameplace=<名前>` | アプリ名を変更。英数字・`_`・`-` を使用 |
| `--datapath=<ディレクトリ>` | アプリ名のディレクトリを作る親の保存先を指定 |
| `--uri=<URL>` / `--url=<URL>` | 起動時に開くHTTP・HTTPS URLを指定 |

Windowsで通常環境と分ける例です。空白を含むパスはシェルに応じて引用します。

```powershell
.\Siki.exe --nameplace=Siki-test --datapath="D:\Siki Data"
```

この例ではユーザーデータは `D:\Siki Data\Siki-test`、プロファイルはその下の `profile` になります。`--datapath` に `profile` 自体を指定するわけではありません。

HTTP・HTTPS URLを引数として渡す方法や `siki:` のURIを渡す処理もあります。掲示板を開く目的なら、まず通常のURLを指定して動作を確かめます。

## ポータブルモードとの関係 {#portable}

明示的な名前・保存先などの指定がない場合、対応する配布形式では実行ファイル脇の `data` の存在を調べ、ポータブルの保存先として使います。アップデーター付きの配布形式などでは条件が異なります。

コマンドラインで保存先などを指定すると、通常のポータブル判定や `siki-option.txt` の読み込みより優先されます。意図しない空の環境が開いたときは、データが消えたと判断する前に起動引数と保存先を確認してください。

## siki-option.txt {#option-file}

コマンドラインの明示指定やポータブル判定を使わないときは、通常のユーザーデータの場所にある `siki-option.txt` を読み込みます。現在選ばれたプロファイル内へ置けば必ず読まれる、というファイルではありません。

```text
nameplace=Siki-test
datapath=D:\Siki Data
uri=https://example.com/
```

一行ずつ指定します。任意のChromiumスイッチを追加する前に、利用している版での対応と影響を確認してください。

保存先が変わっても元のデータを自動で移すわけではありません。必要なデータは[別のPC・OSへの移行](../migration/move-data.md)に沿って移します。
