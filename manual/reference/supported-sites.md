# 対応サイトと制限

Sikiは複数の形式の掲示板に対応します。サイトや板ごとに、閲覧、投稿、認証、スレッド作成、画像の扱いは異なります。

## 対応を確認する {#check}

対応する板・スレッドのURLをSikiで開き、対象が認識されるかを確認します。サイトの通常のWebページとして開くことと、板・スレッドとして閲覧することは別です。

| 内蔵対応の例 | 確認すること |
| --- | --- |
| 5ch・PINK、おーぷん、したらば、JPNKNなど | サイトごとのURL形式、投稿条件、認証、利用できる操作 |
| ふたばなどの画像掲示板 | 板・スレッドの方式、画像・投稿欄・アップロードの違い |
| Reddit、4chanなど | サイト固有の表示や機能の制限。Redditの返信投稿は対象外 |
| その他の独自方式のサイト | 対応プラグイン、URL形式、閲覧と投稿の範囲 |

これは対応形式の代表例です。全サイトの現時点の接続成功や、すべての機能の利用を示す一覧ではありません。利用中の版の配布案内・更新内容も確認してください。

## 閲覧と投稿の条件 {#capabilities}

| 確認する機能 | 注意点 |
| --- | --- |
| 板・スレッドの取得 | URL形式やサイト側の仕様変更、取得できる範囲が異なる |
| 返信投稿 | 閲覧できても投稿できるとは限らない。認証や規制もある |
| 新規スレッド作成 | 対応の有無や作成条件がサイト・板で異なる |
| 画像・動画 | リンク先、配信形式、外部ページ表示などで動作が異なる |

ブラウザでの認証が必要な場合は、そのサイトとSikiの案内に従います。サイト全体の障害や規制を、表示設定の変更だけで解決できるとは限りません。

## 旧版の説明と異なる場合 {#changes}

旧版から一部サイトの内蔵対応やRedditへの返信投稿などを終了しています。旧資料にあるサイトや手順が現在も使えるとは限りません。[移行ガイド](../migration/from-previous.md#removed)を確認してください。

取得できない場合は[通信・取得の対処](../troubleshooting/network.md)、投稿できない場合は[書き込みの対処](../troubleshooting/posting.md)へ進みます。
