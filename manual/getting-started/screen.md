# 画面の見方

基本の画面は、板からスレッドを選び、その内容を読む構成です。配置やボタンは変更できるため、以下は役割をつかむための説明です。

![上部にURL入力欄、左にサイドパネル、中央に板とスレッド、下部に書き込み欄とワークスペースを置いた説明図](/images/screen-map.svg)

*画面の役割を示す説明図です。実際の配置はレイアウトや設定により異なります。*

## 主な領域 {#areas}

| 領域 | 役割 |
| --- | --- |
| メインメニュー | 表示、ツール、設定、ヘルプなどの入口 |
| URL入力欄 | 板やスレッドのURLを指定して開く |
| サイドパネル | BBSMenu、お気に入り、履歴、保存ログ検索などを表示する |
| 板の表示領域 | スレッド一覧を表示し、更新・検索・並び替えを行う |
| スレッドの表示領域 | レス本文を読む。更新、検索、表示の絞り込みを行う |
| 書き込み欄 | 投稿する本文や名前・メールなどを入力する |
| ワークスペースの切り替え | 用途ごとに開いているタブや配置を切り替える |

## 板とスレッドを広く表示する {#layout}

画面上部のレイアウト操作から「縦／横」「単体／並列」「配置交換」を使えます。単体表示は、今使う領域を広く読む場合に便利です。[レイアウト](../customization/layout.md)で詳しく説明します。

ボタンが見えない場合はレイアウトメニューを開きます。狭い画面では、ボタンが一時的にメニュー内へ移る場合もあります。

## 設定と補助画面 {#windows}

設定画面では項目を検索・変更します。画像を詳しく見るときは画像ビューア、保存済みの内容を管理するときはデータビューアなど、用途に応じた画面を開きます。

書き込み欄は配置によってメイン画面内や別ウィンドウに表示されます。開いた画面の名前だけでなく、どの板・スレッドが対象かも確認します。

## 操作を見つける {#find-actions}

アイコンだけでは役割が分からない場合は、マウスを重ねて説明を確認します。右クリックメニューには、クリックした板・レス・IDなどの対象に応じた操作が表示されます。

[タブ](../basics/tabs.md)、[検索](../basics/search.md)、[設定の適用範囲](../customization/settings.md)も合わせて確認してください。
