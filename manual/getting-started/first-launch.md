# 初回起動

初めて起動すると、配置や見た目を選ぶ案内が表示されます。選んだ設定は後から変更できます。

![新しい作業用プロファイルで起動したSikiの「ようこそ」画面。右側の矢印から初期設定へ進めます](/images/first-launch.png)

## 初期設定を進める {#onboarding}

1. 「ようこそ」の案内から進みます。
2. 「レイアウトの選択」で、板とスレッドの並べ方を選びます。
3. 「カラーの選択」で見やすい配色を選びます。
4. 「スケーリング」で画面全体の大きさを調整します。
5. 「初期設定完了」まで進み、案内を閉じます。

スケーリングはアプリ全体の大きさを変える操作です。レス本文だけの文字サイズを調整する設定とは異なります。

## 最初の板を開く {#first-board}

対応する板のURLが分かる場合は、画面上部のURL入力欄へ貼り付けて移動します。スレッドのURLから直接開くこともできます。

URLが分からない場合は、初期設定完了画面のBBSMENU設定や、設定の「BBSMenu」から板一覧を設定します。BBSMenuは板のリンク一覧です。設定後に一覧を更新し、サイドパネルのBBSMenuから板を選びます。

具体的な操作は[板を開く・スレッドを探す](../basics/boards.md)を参照してください。

## あとからやり直す {#reopen-intro}

Welcomeページの「イントロページを起動する」から案内を開き直せます。案内の選択は、その場の設定変更につながるため、現在の表示を変えたい項目だけ操作します。

設定の場所を直接探す場合は[画面の見方](screen.md)と[設定の探し方](../customization/settings.md)を参照してください。

## 何も表示されないとき {#empty-screen}

初期設定を終えただけでは、すべてのサイトの板一覧が自動的にそろうわけではありません。板やスレッドのURLを開くか、BBSMenuを設定します。取得に失敗した場合は[通信・取得の対処](../troubleshooting/network.md)を確認してください。
