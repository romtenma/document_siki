# Sikiとは・基本用語

![Sikiのワードマーク](/images/siki-wordmark-blue.svg)

Sikiは、複数の掲示板を共通の画面で読むためのデスクトップアプリです。Windows・macOS・Linuxで利用でき、対応するサイトでは書き込みもできます。

## 最初に覚える用語 {#terms}

| 用語 | 意味 |
| --- | --- |
| サイト | 掲示板を提供するサービス。サイトによって使える機能や投稿の条件が異なります |
| 板 | 話題や分野ごとにスレッドをまとめた場所 |
| スレッド | 1つの話題について投稿が集まる場所 |
| レス | スレッドにある個々の投稿 |
| タブ | 開いている板やスレッドを切り替えるための入口 |
| ワークスペース | タブや画面の配置を用途ごとにまとめる単位 |
| ログ | Sikiが取得して保存した板・スレッドのデータ |
| プロファイル | 設定や閲覧データなどを保存する領域 |

サイトによって「トピック」「コメント」などの名称も使われます。このマニュアルでは、共通する操作を板・スレッド・レスという言葉で説明します。

## 初めて使うときの順序 {#start}

1. [インストールと更新](install.md)で、お使いの環境に合う配布形式を選びます。
2. [初回起動](first-launch.md)で、配置や文字の大きさを調整します。
3. [画面の見方](screen.md)を確認します。
4. [板を開く](../basics/boards.md)から、[スレッドを読む](../basics/threads.md)へ進みます。
5. 投稿したい場合は、[書き込み](../basics/posting.md)を確認します。

## 閲覧と書き込みの違い {#reading-posting}

板を読めることと、その板に投稿できることは別です。投稿には、サイトの認証や規制、投稿形式への対応が必要な場合があります。[対応サイトと制限](../reference/supported-sites.md)も確認してください。

## 以前から使っている場合 {#existing-users}

旧版から更新する場合は、[1.0.0への移行ガイド](../migration/from-previous.md)を先に確認します。新規の導入手順で現在の保存データを置き換えないよう、バックアップと保存先を確認してください。
