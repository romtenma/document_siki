# 旧バージョンから1.0.0へ

1.0.0に向けた変更では、設定画面、表示、保存形式、配布・更新方法などを見直しています。旧版の手順や画像と同じ場所に項目があるとは限らないため、更新前にデータを保管し、必要な設定を確認します。

## 更新前に保管する {#before-update}

1. 現在のバージョンと配布形式、保存先を確認します。
2. 設定のバックアップを作成します。
3. Sikiを終了し、プロファイルと必要なログ・画像を別にコピーします。
4. 新しい配布一式を使って更新します。

[バックアップと復元](../troubleshooting/backup.md)と[更新方法](../getting-started/install.md#updates)を参照してください。以前の `app.asar` 単体を置き換える方式を、新しい配布形式の更新に使いません。

## 保存形式と互換性 {#data-format}

| 対象 | 変更と注意点 |
| --- | --- |
| お気に入り・ローカル板 | SQLiteへ移行します。移行後の編集を旧形式へ書き戻す仕組みではありません |
| スレッドログ | レス本文と画像・動画などの保存方法が変わっています。新形式を旧版で開くと同じ表示になるとは限りません |
| 既読位置・タブ・ツリー・ミュート | 保存や復元の扱いが変わっています。旧版で更新後の状態を読み戻せるとは限りません |

新しい版で操作したデータを、そのまま旧版でも使えるとは考えず、旧版へ戻す場合は更新前の控えを使います。

## 設定の場所と扱い {#settings-changes}

| 旧版の項目・手順 | 新しい確認先 |
| --- | --- |
| サイト編集からの表示調整 | 通常の共通設定と「サイト・板別設定」を使い分ける |
| 開いたタブへの設定反映 | 項目ごとの継承元、個別指定、保存と反映のタイミングを確認する |
| 板・スレッドの並び | ヘッダのレイアウト操作とワークスペースの配置設定 |
| 保存ログ検索の正規表現 | 対象項目、比較方法、AND / ORなどの条件を指定する方式 |
| NGの「より薄く」 | 「小さく表示」への変更を確認する |
| 一部のレス表示設定 | 通常の表示設定からレススキン側へ移った項目を確認する |

レススキンへ移った「画像URLを表示しない」「ツリー表示のときにアンカー、引用レスを表示しない」「新着の>>1へのアンカーをレスツリーに含めないようにする」は、必要に応じてスキン編集で設定し直します。

個別指定の考え方は[設定の適用範囲](../customization/settings.md)、配置は[レイアウト](../customization/layout.md)、検索は[保存ログ検索](../features/log-search.md)で確認できます。

## 独自のスキン・CSSを使っている場合 {#customization}

レス内の画像・カード・動画・アンカーを表す要素や、動画の親子構造が変わっています。要素名や直下の関係を指定したCSSは、確認・修正が必要になる場合があります。旧設定の `lineGap` はレイアウトに反映されません。

カスタマイズの控えを残し、表示が変わった箇所を絞って確認します。原稿や旧WikiのCSS例を、現在の画面へ無検証でそのまま適用しないでください。

## 廃止・対応終了した内容 {#removed}

プロキシボード、Windows 32bit版、一部サイトの内蔵対応などは終了しています。Redditへの返信投稿は終了し、閲覧の用途で扱います。準備版にあったbbsync連携を、現在使える同期機能として扱いません。

旧資料に説明が残っていても、現行の利用手順とは限りません。[対応サイトと制限](../reference/supported-sites.md)を確認してください。

## 更新後に確認する {#after-update}

お気に入り、開いているタブ、読んだ位置、板やスレッドの表示方法、独自のスキン・操作割り当てを確認します。違いがある場合は、データを削除する前に継承元や表示設定を調べます。

不明な点は[困ったとき](../troubleshooting/index.md)から症状を選びます。バージョン固有の変更内容は、更新時のリリースノートも確認してください。
