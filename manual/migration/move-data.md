# 別のPC・OSへの移行

環境を引き継ぐ場合は、設定だけでなく、ログ・画像などもどこへ保存しているかを確認します。まず元の環境を残したまま、新しい環境で内容を確かめます。

## 元のPCで控える {#source}

1. Sikiの版と、Welcomeの「Sikiの使うファイル」に表示されるデータ保存先を記録します。
2. 設定の「システム」→「ファイルの場所」で、ログ・画像・プラグイン・バックアップの外部保存先を確認します。
3. 設定バックアップを作成します。
4. Sikiを終了し、プロファイルと外部保存した必要なデータを別の場所へコピーします。

SQLiteなどのDBを利用しているため、起動中に一部だけコピーする方法は避けます。設定バックアップのZIPだけではログや画像まで一式移せない点にも注意します。[バックアップと復元](../troubleshooting/backup.md)で対象を確認してください。

## 新しいPCで配置する {#destination}

1. 移行元と互換性のあるSikiを導入し、一度起動して保存先を確認します。
2. 新しいPCのSikiを終了し、移行先の初期データも控えます。
3. 必要なプロファイルと外部データを配置します。既存の環境がある場合は上書きする内容を確認します。
4. 起動して、保存先・ログ・お気に入り・ローカル板・タブなどを確かめます。

旧版からの移行を同時に行う場合は、[旧バージョンから1.0.0へ](from-previous.md)も確認します。新しい版で使ったプロファイルを、そのまま古い版へ戻して使わないでください。

## PC・OSで変わる項目 {#environment}

| 項目 | 確認すること |
| --- | --- |
| 絶対パス | ログ・画像・保存先、外部ツール、同期ファイルなどを新しいパスへ変更 |
| テーマとCSS | フォント、背景画像、ファイル名の大文字小文字、参照先 |
| キー・マウス | OSの修飾キー、予約キー、入力機器の違い |
| プラグイン | 対応OS、外部プログラム、実行ファイルのパス |
| 認証・API | ログインのやり直しや接続の再確認が必要か |

設定ファイルにはログイン情報やAPIキーが含まれる場合があります。移行用のコピーは自分で管理し、共有する資料へ添付しないでください。

## 移行後に確かめる {#verify}

保存ログ・画像を開けること、設定を変えて再起動後も残ること、参照先が元のPCのパスになっていないことを確認します。元のPCのデータは確認が終わるまで保管します。Sync2chによる[同期](../features/sync.md)だけでは、これらのデータ一式は移りません。
