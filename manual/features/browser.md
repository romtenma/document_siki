# ブラウザビュー

ブラウザビューは、Sikiの画面内でWebページを開く機能です。掲示板のレス表示とは別の画面として、ページの閲覧や対応サービスの操作に利用します。

## 開く・閉じる {#open-close}

リンクのメニューなどから「ブラウザビューで開く」を選びます。通常表示では外側のクリックやEscで閉じられます。上部の「閉じる」ボタンでも閉じられます。

普段のブラウザを使いたい場合は「外部ブラウザで開く」を選びます。ブラウザビューと外部ブラウザでログイン状態が同じになるとは限りません。

## 固定・移動・サイズ変更 {#pin}

上部のピンの「固定表示」を押すと、Sikiのほかの部分も操作しながらページを表示できます。「固定を解除」で通常表示へ戻ります。固定中はEscや外側クリックで閉じる通常表示の動作が変わるため、閉じるときは上部のボタンを使います。

タイトルバーをドラッグすると移動、周囲の枠をドラッグするとサイズを変更できます。移動・サイズ変更中はEnterで確定、Escで取り消します。位置やサイズの保存に失敗した場合は、画面のメッセージを確認します。

## ページを操作する {#navigation}

戻る・進む・再読み込みの操作を利用できます。ビューにフォーカスがあるときはAlt+←／Alt+→で戻る・進む、Ctrl+R（macOSでは⌘+R）でキャッシュを無視した再読み込みができます。

[マウスジェスチャー](../customization/mouse.md)にもブラウザビュー用の割り当てがあります。この範囲では、戻る・進む・再読み込み・上下端への移動・閉じるに対応します。

ページが開かない、ログインを完了できないなどの場合は、外部ブラウザで同じURLを確認し、Sikiの掲示板取得の問題と分けて調べます。
