# お気に入り

よく使う板やスレッドを登録し、後から開きやすくできます。タブを閉じる操作と、お気に入りから登録を外す操作は別です。

## 登録する・開く {#add-open}

1. 登録したい板やスレッドを開きます。
2. 対象のメニューからお気に入りに関する操作を選びます。
3. サイドパネルのお気に入りを開き、登録された項目を確認します。
4. 項目を選ぶと、登録した板やスレッドを開けます。

画面内の★から操作できる場合もあります。レスに付けるマークの★とは対象が異なるため、板・スレッドのお気に入り操作かを確認してください。

## フォルダーで整理する {#organize}

お気に入りのメニューからフォルダーや登録項目を管理します。フォルダーを板として開く操作では、その配下に登録したスレッドを一覧で確認できます。

タイトルやメモを使って、登録した理由や用途を残せます。登録項目の整理と、元のサイト上のスレッドを変更することは別です。

## タブ・履歴との違い {#difference}

| 機能 | 主な用途 |
| --- | --- |
| タブ | 今開いている表示を切り替える |
| お気に入り | 継続して使う板やスレッドを登録する |
| 履歴 | 以前に開いた場所を探す |

登録を外す場合は対象のお気に入り操作を確認します。保存ログの削除が目的でない場合は、ログ削除付きの操作と混同しないでください。

お気に入りのデータも[バックアップ](../troubleshooting/backup.md)の対象として考えます。旧版からの保存形式の変更は[移行ガイド](../migration/from-previous.md#data-format)を確認してください。
