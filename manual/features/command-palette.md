# コマンドパレット

コマンドパレットは、名前を入力して板・スレッドや操作を選ぶ入口です。メニューをたどらずに目的の項目へ移動できます。

## 開いて選ぶ {#open}

設定メニューの「コマンドパレットを開く」を選ぶと、アドレスバーがコマンドを探す入力欄になります。同じ名前のコマンドをキーなどへ割り当てても開けます。コマンドIDは `control:focus.commandpallet` です。

現在の標準定義ではCtrl+Shift+P、macOSでは⌘+Shift+Pを使います。旧資料のCtrl+P／⌘+Pとは異なります。過去の設定が残っている場合は[キーボードショートカット](../customization/keyboard.md)の「全体」で実際の割り当てを確認してください。

入力すると候補が絞られます。↑・↓で選び、Enterまたはクリックで開きます。取り消すときはEscを押します。

## 検索の種類を切り替える {#modes}

| 入力 | 探すもの |
| --- | --- |
| そのままタイトルなどを入力 | 開いている・最近閉じた板やスレッド、お気に入り、BBSMenuの板など |
| `>` に続けて入力 | コマンド |

パレットをコマンドの操作から開くと、先頭に `>` が入ります。たとえば `>設定` と入力して「設定を開く」を選ぶと設定画面へ進めます。旧資料の板専用の `b:` 切り替えは、現在の入力欄では使いません。

候補には表示名とコマンドIDが出ます。名前だけで判断しにくい操作は、[コマンド一覧](../reference/commands.md)で確認してください。

板やスレッドが候補にない場合は[板を開く・スレッドを探す](../basics/boards.md)へ進みます。パレットの候補検索と、掲示板全体の検索・[保存ログ検索](log-search.md)は検索対象が異なります。
