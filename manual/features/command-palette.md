# コマンドパレット

コマンドパレットは、名前を入力して板・スレッドや操作を選ぶ入口です。メニューをたどらずに目的の項目へ移動できます。

## 開いて選ぶ {#open}

標準の割り当てではCtrl+P、macOSでは⌘+Pで開きます。「コマンドパレットにフォーカス」コマンドも使えます。割り当てを変更している場合は[キーボードショートカット](../customization/keyboard.md)で確認します。

入力すると候補が絞られます。↑・↓で選び、Enterまたはクリックで開きます。取り消すときはEscを押します。

## 検索の種類を切り替える {#modes}

| 入力 | 探すもの |
| --- | --- |
| そのままタイトルなどを入力 | 開いている・最近閉じたスレッドなど |
| `b:` に続けて入力 | 板 |
| `>` に続けて入力 | コマンド |

たとえば `>設定` と入力して「設定を開く」を選ぶと設定画面へ進めます。候補の名前だけで判断しにくい操作は、[コマンド一覧](../reference/commands.md)でIDと用途を確認してください。

板やスレッドが候補にない場合は[板を開く・スレッドを探す](../basics/boards.md)へ進みます。パレットの候補検索と、掲示板全体の検索・[保存ログ検索](log-search.md)は検索対象が異なります。
