# ワークスペース

ワークスペースは、開いている板・スレッドとタブをまとめて切り替える単位です。ニュース用、趣味用など、同時に開く内容を分けたいときに使います。

## 作成して切り替える {#create-switch}

1. 画面のワークスペース切り替えボタンを開きます。
2. 追加の「＋」からワークスペースを作ります。「新規ワークスペース作成」コマンドからも追加できます。
3. 新しいワークスペースで板やスレッドを開きます。
4. 切り替えボタンで元のワークスペースへ戻り、タブのまとまりが切り替わることを確認します。

名前やアイコンは、設定の「ワークスペース」で編集する対象を選んで変更できます。「次のワークスペースへ移動」「前のワークスペースへ移動」をキーなどへ割り当てる方法もあります。

## レイアウトを共通にする・分ける {#layout}

ワークスペース0のレイアウトが共通設定になります。それ以外では「レイアウト」を選べます。

| 選択 | 配置変更の範囲 |
| --- | --- |
| 共通（ワークスペース0） | 共通レイアウトを使うワークスペースにも反映 |
| このワークスペース独自 | 選んだワークスペースだけに保存 |

独自の配置を始めるときは「共通レイアウトをコピー」で現在の共通配置を取り込めます。すでに独自の配置がある場合は、その配置を置き換える操作です。共通へ戻した場合も、保存済みの独自設定は保持されます。

配置の操作は[レイアウト](../customization/layout.md)、配色は[テーマ・配色・背景](../customization/themes.md)を参照してください。

## 接続設定とタブの保持 {#options}

ワークスペースごとに読み込み・書き込み用のプロキシやユーザーエージェントを指定できます。用途上必要な場合だけ設定し、取得・投稿ができなくなったときはこの指定も確認します。

「終了時にスレッドタブを保持しない」「終了時に板タブを保持しない」を有効にすると、ロック・お気に入り以外のタブを終了時に保持しません。次回も開きたい内容がある場合は、終了前に保持方法を確認してください。

## 閉じる前に確認する {#close}

不要なワークスペースは「ワークスペースを閉じる」から閉じます。再び参照する板・スレッドは、先に[お気に入り](bookmarks.md)へ登録しておくと探し直せます。誤操作を防ぐためのワークスペースのロックも利用できます。
