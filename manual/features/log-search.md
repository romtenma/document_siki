# 保存ログ検索

過去に取得・保存したスレッドを横断して探す機能です。今の板やスレッドだけを探す場合は[表示中の検索](../basics/search.md)を使います。

## 検索する {#search-logs}

1. 「保存ログ検索を開く」から検索画面を開きます。
2. 範囲を「保存済み全体」「サイト」「板」「開いているスレッド」から選びます。
3. 開始日・終了日を確認します。古い投稿を探すときは期間を広げます。
4. 「条件1の対象」で本文やタイトルなどを選び、比較方法と値を入力します。
5. 検索を実行し、進捗と結果を確認します。

この検索のために、未取得の過去ログを外部サイトから自動収集するわけではありません。保存していないレスは検索できません。

## 条件を組み合わせる {#conditions}

| 項目 | 使い方 |
| --- | --- |
| 対象 | タイトルか本文、本文、名前、ID、BBSSLIPなどを選ぶ |
| 比較方法 | 含む・含まない・等しい・等しくないを使い分ける |
| 条件を追加 | 別の項目の条件を追加する |
| すべて満たす（AND） | すべての条件に一致する内容を探す |
| いずれかを満たす（OR） | どれかの条件に一致する内容を探す |
| 日時不明も含める | 期間指定時に、投稿日時を判断できない内容も含める |

全角半角・英字大小の同一視は、対象項目によって適用される範囲が異なります。IDなどを正確に探す場合は、対象と比較方法を確認してください。旧版の保存ログ検索の正規表現指定とは方式が異なります。

## 結果を読む {#results}

結果を選ぶと、該当レスと続きのプレビューを確認できます。「スレッドを開く」から元のスレッドへ進めます。結果が多い場合は期間や範囲・条件を絞り直します。

検索中は「停止」で処理を止められます。検索終了、停止、上限到達、エラーは別の状態なので、表示された結果の範囲も確認します。

## 表示先と再開 {#placement}

設定の「システム」→「検索」→「ログ検索の表示先」で、板タブまたはサイドパネルを選べます。変更は次に開く検索から使われ、すでに開いた検索は残ります。

サイドパネルの検索はワークスペースごとに保持します。「板タブへ複製」で条件を別の検索タブへコピーできます。再起動後は条件を確認して再実行し、検索結果を取得してください。

## 見つからないとき {#not-found}

まず期間、対象サイト・板、比較方法を確認します。初期の期間より古い投稿や、日時不明のログが除外されている場合があります。ログを移した場合は[保存先](../reference/data-locations.md)も確認してください。
