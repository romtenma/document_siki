# 自動更新と実況

新着を取得する操作と、取得したレスを画面に流す操作は別々です。更新されないときはオートロード、表示が進まないときはオートスクロールを確認します。

## 自動更新する {#autoload}

読みたいスレッドでオートロードを有効にします。ワークスペースの設定には「アクティブなスレッドは常にオートロード状態にする」もあります。タブを切り替えたときの動作が違う場合は、この設定を確認してください。

更新間隔や取得の可否はサイトの制限にも影響されます。取得エラーが出るときは更新を繰り返す前に[通信の確認手順](../troubleshooting/network.md)へ進みます。

## オートスクロールを開始・停止する {#autoscroll}

スレッドのオートスクロール操作を開き、動作モードと速度を選びます。「オートスクロール:開始」「オートスクロール:停止」コマンドでも操作できます。

モードにはティック、スクロール、カーソル、読み上げがあります。速度の上げ下げ、リロード間隔の自動設定・手動指定もコマンドへ割り当てられます。

過去のレスへ戻って読みたいときはいったん停止します。設定の「スレッド」では、末尾付近でのホイール操作でオートスクロールを再開・停止するかも変更できます。

## 動画上・流し表示を使う {#overlay}

1. 対象のスレッドを「タブを別ウィンドウで開く」で開きます。
2. 別ウィンドウ上部の「別ウィンドウの表示モード」を選びます。
3. 通常のレス表示へ戻すときは「通常」を選びます。

| モード | 用途 |
| --- | --- |
| 通常 | 別ウィンドウで普通に読む |
| 動画上 | 動画などに重ねてレスを表示する |
| 流し | コメントを流して表示する |

動画上表示では背景の濃さ、流し表示では文字の大きさなどを調整できます。表示位置や速度を確かめてから視聴に使います。旧版の動画メニューにあった「実況コメント」入力欄とは操作が異なります。

投稿は[書き込む・スレッドを作る](../basics/posting.md)を参照してください。表示モードを変えるだけで投稿が送信されることはありません。
