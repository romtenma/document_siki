# NG・強調・ミュート・マーク

読みたくない内容を隠したり、気になる内容を目立たせたりできます。目の前のレスやIDを指定する操作と、条件に合う内容へ継続して適用するルールを使い分けます。

## 使い分けを選ぶ {#choose}

| 機能 | 使う場面 | 主な入口 |
| --- | --- | --- |
| ミュート | レス番号やIDなどを指定して隠す | レスやIDなどの右クリックメニュー |
| NG | 単語・数値・日時などの条件に合う内容を隠す | 設定の「NG/強調」 |
| マーク | レスやIDなどを指定して目立たせる | 対象の右クリックメニュー |
| 強調 | 条件に合う内容を色などで目立たせる | 設定の「NG/強調」 |

NGと強調は同じルール編集画面を使い、表示方法で効果を選びます。ミュートとNGは別に管理するため、片方を解除しても、ほかの指定が残っていれば非表示のままになる場合があります。

## レスやIDをミュートする {#mute}

1. 隠したいレスの番号やIDなどを右クリックします。
2. メニューから、何を対象にするかを確認してミュートの操作を選びます。
3. 対象のレスの表示が変わったことを確認します。

レス番号を対象にする操作と、同じIDのレスを対象にする操作では影響する範囲が異なります。対象や表示場所によってメニューの項目名も変わります。表示中の項目を確認して選んでください。

::: tip 元に戻す入口
通常ミュートで表示が残っている場合は、その部分の右クリックメニューから「ミュートを解除」を選べます。対象が見えない場合は、設定の「NG/強調」にある「ミュート管理（データビューア）」から登録内容を確認します。
:::

## NG・強調のルールを追加する {#add-rule}

1. 設定の「NG/強調」を開きます。
2. レス本文などを対象にするなら「レス」、スレッド一覧を対象にするなら「スレッド」を選びます。
3. 「＋ ルールを追加」を押します。
4. 必要に応じてルール名を入力し、「表示方法」を選びます。
5. 「適用範囲」と「適用条件」を指定します。
6. 「条件の要約」を確認して「保存」を押します。

ルール編集は「保存」で確定します。「キャンセル」で閉じる場合、変更があれば未保存の内容について確認が表示されます。

### 本文の単語を条件にする例 {#word-example}

「レス」のルールで本文を対象にし、表示したくない単語を文字列の条件として指定します。「表示方法」を「NG（本文非表示）」にすると、条件に合うレスの本文を隠せます。

最初は通常の文字列の条件から始めると、意図した対象に一致しているか確認しやすくなります。正規表現や複数条件を使う場合は、条件の要約とエラー表示も確認してください。

## 適用範囲と表示方法を選ぶ {#scope-and-effect}

ルールの「適用範囲」では、全体、サイト、板などの対象を指定します。レスのルールではスレッドも指定できます。表示の設定が継承される仕組みとは別の、ルール自体の適用条件です。

| 表示方法の例 | 結果 |
| --- | --- |
| NG（本文非表示） | 該当するレスの本文を隠す |
| NG（タイトル非表示） | スレッドのルールで、該当するタイトルを隠す |
| 省略表示 | レスを省略して表示する |
| 透明 | 該当部分を表示から取り除く |
| 薄く・小さく表示 | 内容を残しつつ目立ちにくくする |
| 強調・アウトライン | 色や枠で目立たせる |

レスとスレッドでは選べる表示方法が異なります。返信への連鎖や同じIDへの適用を有効にすると、一致したレス以外にも影響します。

## ルールを探す・一時的に止める {#manage-rules}

「NG/強調」の一覧では、名前・条件・適用範囲から検索できます。「NG」「強調・その他」「ワード条件」「無効なルール」で絞り込むこともできます。

ルールを残したまま止めたい場合は、そのルールの有効スイッチをオフにします。再びオンにすると、保存した条件を使えます。一覧では上のルールが優先されるため、複数のルールに一致する場合は順番も確認してください。

## 隠した内容を戻す {#restore}

| 指定した方法 | 戻す方法 |
| --- | --- |
| ミュート | 対象の右クリックメニューで解除するか、ミュート管理で対象を確認する |
| NG・強調のルール | 一覧でそのルールを無効にする。条件を修正する場合は「編集」して保存する |
| ツリーの折りたたみ | [返信ツリーを開く](../basics/threads.md#collapse-tree) |
| フィルターの絞り込み | スレッド上部で選択しているフィルターを確認する |

解除しても表示されないときは、別のルール・ミュート・絞り込みが重なっていないかを確認します。透明表示の対象は画面上で選びにくいため、管理画面から対象を探してください。
