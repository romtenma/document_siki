# AIサイドパネル

AIサイドパネルでは、読み込んだスレッドを要約したり、その内容について質問したりできます。AIの回答に表示された参照レスを開き、元の発言も確認できます。

## 接続先を設定する {#connection}

1. 設定の「AI」→「AIの接続設定」を開きます。
2. 「使用するAI」でGemini、OpenAI、Ollamaのいずれかを選びます。
3. モデル名と、必要に応じてAPIの接続先URLを設定します。
4. Gemini・OpenAIではAPIキーを設定します。設定済みなら、変更する場合だけ新しいキーを入力します。
5. AI設定画面の保存操作を行い、サイドパネルの「設定を更新」で接続表示を確認します。

モデル名は利用先で提供される名前を指定します。Ollamaは、起動しているサーバーとインストール済みのモデルが必要です。接続先を設定しただけでは、スレッドの要約は実行されません。

::: info 送信先と設定ファイル
要約・質問の実行時には、対象のレス本文や質問が選んだ接続先へ送られます。外部サービスでは利用契約や課金条件も確認してください。APIキーはプロファイル内の `misc/ai_setting.js` に保存されるため、設定ファイルやバックアップを第三者へ公開しないでください。
:::

## 要約・質問を実行する {#request}

対象のスレッドを開いてAIサイドパネルの「スレッド」を選びます。パネル上部のスレッド名、接続先・モデル、操作の説明に表示される送信範囲を確認してから実行します。

| 操作 | 対象 |
| --- | --- |
| 全体要約 | 読み込んだスレッド全体の送信可能なレス |
| 新着要約 | 開始番号から最新までのレス。必要なら開始レス番号を指定 |
| 今の状況 | 直近の範囲から現在の話題を整理 |
| 質問・依頼 | スレッドについて入力した質問や依頼 |

NGなどで送信対象から除外されるレスもあります。送信件数・除外件数、分割の表示を確認してください。掲示板全体や、まだ取得していないレスまで自動で調べる機能ではありません。

質問・依頼は入力欄へ書いて「送信」を押します。Ctrl+Enterでも送信できます。レス案の作成を依頼した場合も、回答を確認し、投稿は自分で[書き込み欄](../basics/posting.md)から行います。

## 回答とエラーを確認する {#result}

回答中のレス番号を選ぶと、参照するレスを確認できます。要約で省かれた文脈や発言の意味は、元のレスと照らし合わせます。

エラー時は接続先、モデル名、APIキーの設定状況を確認します。Ollamaではサーバーの起動状態も確認します。設定を変更したら「設定を更新」でパネルへ読み直します。

「Siki」タブの「Sikiへの質問と設定変更」は、現在確認している準備版では未提供の表示です。AIにアプリ設定を変更させる手順は、提供状況を確認してから追加します。
