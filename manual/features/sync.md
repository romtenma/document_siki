# 同期

SikiにはSync2chとスレッド情報を同期する機能があります。設定ファイル・画像・プラグインをまとめて別PCへコピーする機能とは異なります。データ一式の移動は[別のPC・OSへの移行](../migration/move-data.md)を参照してください。

## 接続を設定する {#connection}

「Sync2ch設定」を開き、利用するサービスのユーザー名とパスワードを設定します。画面にはアプリ名とAPI URLの項目もあります。API URLを変えるのは、接続先の指定が必要な場合に限ります。

サービスの利用可否、登録方法、回数などの制限はサービス側で確認してください。Sikiの接続設定が存在することは、外部サービスで現在も同じ条件の利用ができる保証ではありません。

## 対象を選んで同期する {#sync}

1. 同期したいスレッドを[お気に入り](bookmarks.md)へ登録します。
2. お気に入りの編集で同期対象の指定を確認します。「お気に入りを同期状態にする」操作も利用できます。
3. 「スレッド同期」を実行します。
4. 同期結果やエラーを確認し、相手側でもスレッドの登録・既読などの情報を確認します。

同期先の情報も取り込むため、初回は両側の登録内容を確認してから利用します。お気に入りへ入れた内容が、すべて無条件に同期対象になるとは限りません。

## 自動実行のタイミング {#automatic}

設定の「ネットワーク」→「同期設定」では、起動時・終了前・サスペンド前・レジューム後の同期を設定できます。上級設定にあるため、見当たらない場合は上級設定の表示も確認します。

起動時・終了前には、毎回確認する方法と確認なしで同期する方法があります。サスペンド前・レジューム後は有効状態を選びます。まず手動同期で結果を確認し、その後に必要なタイミングだけを有効にしてください。

## 同期できないとき {#troubleshoot}

接続設定、対象の指定、通信状態、サービスから返ったメッセージを順に確認します。利用回数の上限などが表示された場合は、連続して再試行しないでください。

別アプリとの項目ごとの対応には確認が必要です。同期だけに頼らず、[バックアップ](../troubleshooting/backup.md)も残します。
