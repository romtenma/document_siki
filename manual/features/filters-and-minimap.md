# フィルターとミニマップ

フィルターは条件に合うレスを表示する機能、ミニマップはスレッド全体の中の位置を示す機能です。元のレスを削除せずに、読みたい場所を探せます。

## レスを絞り込む {#filter}

スレッドのフィルターを開き、目的の条件を選びます。表示されていないときは「フィルターを開く」コマンド、または設定の「スレッド」→「フィルター」を確認します。

| 条件の例 | 探す内容 |
| --- | --- |
| 画像・動画 | メディアを含むレス |
| 内部リンク・外部リンク | リンクを含むレス |
| 自分のレス | 自分の投稿と判定されたレス |
| 人気レス・返信 | 返信数などの条件に合うレス |
| 入力 | 入力した語や条件に合うレス |

条件によっては、該当レスと関係する返信をツリーとして表示できます。表示の範囲は設定の「人気や返信フィルタの表示方法」「自分のレスフィルタの表示方法」でも変わります。

## 元の表示へ戻す {#clear}

「フィルターを解除する」で絞り込みを解除します。レスが消えたように見えるときは、検索・フィルター・[NGやミュート](ng-and-mute.md)のどれが働いているかを順に確認してください。

フィルターは、読み込んでいるスレッドの表示を対象にします。別のスレッドも含めて保存済みの本文を探すには[保存ログ検索](log-search.md)を使います。

## ミニマップで移動する {#minimap}

スレッド脇のミニマップは、画像、リンク、返信などの位置を点で示します。目的の位置をクリックして、その付近のレスへ移動します。現在の表示範囲も帯で確認できます。

表示する印や左右の位置は、設定の「スレッド」→「ミニマップ」で変更します。幅や点の大きさ・色などの見た目はテーマ編集で調整できます。クリック時の移動方法も設定できるため、期待する位置へ移動しない場合は「ミニマップクリック時の動作」を確認します。

文字列から場所を探す場合は[板・スレッド内を検索する](../basics/search.md)、返信関係をたどる場合は[スレッドを読む](../basics/threads.md)を参照してください。
