# 画像のアップロード・編集

画像のアップロードは、画像ファイルを外部サービスへ送り、そのURLなどを投稿欄へ入れる操作です。掲示板へのレス投稿とは別に行われます。

## 画像を選んで準備する {#prepare}

1. 「画像を選択してアップロード」を開き、ファイルを選びます。
2. プレビュー、ファイル名、容量を確認します。
3. 必要に応じて拡大縮小や文字入れを行います。
4. 送信先を選び、そのサービスの設定と対応形式を確認します。

画像に個人情報が含まれていないかもプレビューで確認してください。ビューアで表示できる形式が、送信先でも受け付けられるとは限りません。

## アップロードして投稿欄へ入れる {#upload}

編集内容と送信先を確かめてからアップロードを実行します。成功後に得られたURLやファイル名を投稿欄で確認し、本文を整えてから掲示板へ投稿します。

APIキーやログインが必要な送信先では、送信先の設定を先に済ませます。送信先の認証と、掲示板の書き込み認証は別のものです。

### あぷ小＠ふたば {#futaba}

Sikiの送信先には「あぷ小＠ふたば」があります。この送信機能の容量上限は3,000,000バイトで、削除キーは自動保存されます。APIキーやログインの設定は不要です。

ふたばの書き込み欄へ挿入するときはファイル名、それ以外ではURLを使う動作があります。挿入結果を投稿前に確認してください。サービス側の保存期間や受け付け条件が変わる可能性もあるため、永続的な保管先としては扱わず、手元の原本を残します。

## 履歴と送信結果を確認する {#history}

「アップロード履歴」では送信した画像と結果を確認できます。対応する履歴には、サーバー上の画像を削除する操作もあります。削除キーなどが必要なので、別のPCへ移るときは[データの移行](../migration/move-data.md)も確認します。

あぷ小＠ふたばへの送信が成功したか不明な場合は、「結果を再確認」で結果を調べられます。これは同じ画像を再送する操作ではありません。状態を確認してから再試行し、重複したアップロードを避けます。

アップロードできてもレスを書き込めない場合は[書き込めない](../troubleshooting/posting.md)、表示できない場合は[画像・動画が表示されない](../troubleshooting/media.md)を参照してください。
