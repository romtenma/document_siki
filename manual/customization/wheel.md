# ホイールジェスチャー

ホイールジェスチャーは、ホイールを回す場所や、一緒に押すキー・ボタンによってコマンドを実行する機能です。通常のスクロール距離の調整とは別の設定です。

## 標準の操作を確認する {#defaults}

| 場所 | 操作 | 標準の動作 |
| --- | --- | --- |
| スレッド・板のタブ上 | 上／下 | 前／次のタブ |
| ワークスペース切り替え上 | 上／下 | 前／次のワークスペース |
| 検索欄 | 上／下 | 前／次の検索結果 |
| スレッド表示エリア | Ctrl+上／下 | タブの文字を大きく／小さく |
| アプリ全体 | Ctrl+Shift+上／下 | 画面の拡大／縮小 |

タブ上の操作は、設定の「タブ」にあるホイール操作の有効状態にも影響されます。過去に設定ファイルを編集した場合は、表とは異なる動作になることがあります。

## 割り当てを変更する {#edit-file}

現在の設定画面には、キーや方向列と同じ形式のホイール割り当て編集画面はありません。詳細な割り当ては、プロファイルの `components/wheel.js` を編集します。

Sikiを終了し、元のファイルを控えてから変更します。ファイル全体を置き換えず、変更したい対象の設定を編集してください。次の例は検索欄で上下に検索結果を移動する定義です。

```json5
{
  '.search-container': {
    U: ['search:goto.prev', '前の検索結果'],
    D: ['search:goto.next', '次の検索結果'],
  },
}
```

`U`・`D`・`L`・`R` は方向、続く `S`・`C`・`A`・`M` はShift・Ctrl・Alt・Metaです。複数指定時はこの順序で並びます。配列の先頭がコマンド、次が説明です。ボタン併用には別の符号化もあるため、既存の定義と照合して変更します。

起動後に変更した場所だけで試し、読み込みエラーや意図しない動作があれば終了して控えへ戻します。[コマンド一覧](../reference/commands.md)と[保存先](../reference/data-locations.md)も参照してください。

## スクロールだけを調整する {#scroll}

スクロールの距離・加速度・滑らかさは、設定の「マウス」→「ホイール回転時のスクロール」で調整します。トラックパッドで更新が暴発する場合は、トラックパッドの設定や[表示・動作の確認](../troubleshooting/display.md)も確認します。
