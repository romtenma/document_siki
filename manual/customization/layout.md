# レイアウト

板の一覧とスレッドを並べたり、片方を広く表示したりできます。画面上部のレイアウト操作、またはレイアウトメニューを使います。

## 基本の切り替え {#controls}

| 操作 | 動作 |
| --- | --- |
| 縦／横 | 板とスレッドを上下・左右の並びに切り替える |
| 単体／並列 | 片方だけを広く表示する・直前の並列配置へ戻す |
| 配置交換 | 並列では板とスレッドの順番を交換する。単体では表示対象を切り替える |

*左から、レイアウトメニュー、縦／横、単体／並列、配置交換です。ボタンの表示は設定で変わります。画面画像は選ぶと原寸で開けます。*

![板とスレッドを左右・上下に並べる例、並列で順番を交換する例、単体で片方を表示する例を示した図](/images/layout-modes.svg)

単体表示中は「縦／横」が無効になります。板からスレッドを開くと、単体表示を保ったままスレッドへ切り替わります。板へ戻る場合は「板を開く」などの入口を使います。

## ボタンやパネルが見えないとき {#hidden-controls}

レイアウトメニューの「ボタンの表示」で、切り替えボタンの表示を調整できます。すべてのボタンを隠しても、メニューの入口は残ります。狭い画面では一部がメニューへ退避する場合があります。

メインメニューの「表示」から、サイドパネルや書き込み欄の表示も確認できます。表示対象を変える操作と、その領域のタブを閉じる操作は別です。

## ワークスペースごとに保存する {#workspace-layout}

設定の「ワークスペース」で対象を選び、「レイアウト」を確認します。

- **共通（ワークスペース0）**：ワークスペース0の配置を使います。共通利用中の配置変更は、共通側にも保存されます。
- **このワークスペース独自**：そのワークスペースだけの配置を使います。最初は共通の配置から始めます。

共通へ戻しても独自設定は保持されます。「共通レイアウトをコピー」は、保存済みの独自設定を現在の共通設定で置き換える操作です。

配置には、分割方向・順番・サイズ、パネル、書き込み欄などが含まれます。個々のスレッドの表示方法やスキンの範囲は[設定の適用範囲](settings.md)を参照してください。
