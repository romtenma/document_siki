# ユーザーコマンド

ユーザーコマンドは、既存のコマンドに引数や実行条件を付けて登録する機能です。メニューに追加したり、キーやジェスチャーから呼び出したりできます。

## 画面から登録する {#create}

1. 設定の「ユーザーコマンド」を開き、追加操作を選びます。
2. コマンドのIDと表示名を入力します。
3. 実行モードで単一コマンド、またはシーケンスを選びます。
4. 実行するコマンドとパラメーターを設定します。
5. 表示場所・条件を確認し、「保存」します。

シーケンスでは複数の操作を並べます。順序によって対象や状態が変わるため、まず一つずつ確認してから組み合わせてください。登録後の一覧はドラッグで並び替えられます。

## 表示場所と実行条件 {#context}

表示場所には選択範囲、板、レス、ID、画像、タブ、書き込み欄、URLなどがあります。複数選択もできます。コマンドが必要とする対象を得られる場所へ追加します。

条件ではサイト・板を選ぶ方法とカスタム条件を使う方法があります。対象を限定した場合は、そのサイト・板でメニューを開いて確認します。条件を満たさない場所で出てこない場合は、登録失敗とは限りません。

## 選択文字を検索する例 {#search-example}

たとえば、IDを `web.search`、表示場所を「選択範囲」、実行コマンドを `uri:open-external` として、パラメーターへ検索URLを指定できます。

```text
https://www.google.com/search?q=${TEXT:urlencode}
```

`${TEXT}` は選択文字などの文脈から渡される文字列、`:urlencode` はURL用の変換です。文字を選択した場所で実行し、検索先と検索語を確認します。

登録したコマンドを別の設定から呼ぶときは、IDの前に `user:` を付けた `user:web.search` を使います。[キー](keyboard.md)や[ジェスチャー](mouse.md)の割り当て先から選べます。

## 外部プログラムを起動する場合 {#external}

外部プログラムの実行には `core:execute` などを利用します。実行時には確認が表示されます。プログラムのパスと引数を区別し、引用符や空白を含むパスは[外部ツールとの連携](../reference/external-integration.md)に沿って確認します。

既存の `components/usercommand.js` を直接編集する場合は、Sikiを終了して控えを残します。旧資料のサンプル全体を上書きすると、自分で登録したコマンドを失うため、必要な定義だけを追加します。
