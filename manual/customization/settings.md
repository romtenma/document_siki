# 設定の探し方と適用範囲

設定では、表示や操作をまとめて変更したり、特定のサイト・板だけを別の設定にしたりできます。最初に「どこまで同じ設定を使うか」を選ぶと、意図した範囲を変更できます。

## 設定を探す {#find-setting}

設定メニューの「設定を開く」から設定画面を開きます。左側の分類を選ぶか、上部の「設定の検索」で項目名や目的を探します。

| 変えたいこと | 主に開く分類 |
| --- | --- |
| スレッド一覧の表示や並び | 板 |
| 時系列・ツリー、フィルター、ミニマップ | スレッド |
| 投稿欄や名前・メールの既定値 | 書き込み |
| 画像・動画の動作 | 画像/映像 |
| NGやミュートの表示・連鎖 | NG/強調の「動作設定」 |
| 特定のサイト・板だけの値 | サイト・板別設定 |

項目の説明と、変更が反映されるタイミングを確認してから値を変更します。

## 適用範囲を選ぶ {#scope}

| 範囲 | 使う場面 | 主な入口 |
| --- | --- | --- |
| 共通設定 | すべてのサイト・板で使う基本の値を変える | 「板」「スレッド」などの通常の分類 |
| サイト設定 | そのサイトの板で使う値を変える | 「サイト・板別設定」でサイト全体を選ぶ |
| 板別設定 | その板だけ別の値を使う | 「サイト・板別設定」で板を選ぶ |
| このタブだけ | 今開いている表示だけ変える | タブ内の表示操作や「このタブだけ」のコマンド |

![共通設定をサイト、板、タブが順に引き継ぎ、個別に指定した項目を優先する説明図](/images/settings-scope.svg)

たとえば、共通設定では時系列、ある板ではツリー、と指定できます。その板は共通設定を変更しても、独自に指定した表示方法を使います。項目ごとに引き継ぎが決まるため、表示方法だけを変えても、ほかの項目まで独自設定になるわけではありません。

::: info 設定によって対象は異なります
すべての項目をサイト・板ごとに変更できるわけではありません。変更できる項目には設定の継承元や「サイト・板別に変更」の入口が表示されます。ワークスペースなど、別の範囲で保存する設定もあります。
:::

## 共通設定を変更する {#common-settings}

1. 変更したい分類を開きます。例として「スレッド」を選びます。
2. 項目の横が「共通設定」になっていることを確認します。
3. 値を変更し、保存状態と反映時期を確認します。

サイト・板の設定やタブだけの変更を使っている場合は、その個別指定が優先されます。

## サイト・板だけ変更する {#site-board-settings}

1. 左側の「サイト・板別設定」、または項目付近の「サイト・板別に変更」を開きます。
2. サイトを選び、サイト全体を変えるか、特定の板を変えるかを選びます。
3. 対象の項目を変更します。
4. 「このサイトで上書き」「この板で上書き」などの表示で、個別指定になったことを確認します。

[![サイトにwall、適用する範囲にlocal（この板）、設定する項目にスレッドを選んだ設定画面](/images/settings-target.png)](/images/settings-target.png)

*ローカル板を選んだ例です。「サイト」「適用する範囲」「設定する項目」と、その下の編集対象を確認します。画面画像は選ぶと原寸で開けます。*

設定値が共通設定と同じでも、明示的に個別指定した項目は上書きとして扱われます。共通設定に追従させたいときは、値を同じにする操作ではなく、上書きを解除します。

## 上書きを解除する {#reset-override}

サイト・板別の項目で「上書きを解除」を押すと、その項目が上位の設定を再び引き継ぎます。「上書き解除後」に表示される値と継承元を確認できます。

[![表示方法をツリーで上書きした板別設定。上書き解除後の値として共通設定の時系列が表示され、上書きを解除するボタンがある](/images/settings-override.png)](/images/settings-override.png)

*「この板で上書き」の状態です。解除する前に、戻る値と継承元を確認できます。*

[![上書きを解除し、表示方法が時系列と共通設定から継承の表示に戻った状態](/images/settings-inherited.png)](/images/settings-inherited.png)

*解除後は「共通設定から継承」に戻ります。*

これは項目を初期値へ戻す操作とは異なります。上位の設定が変更されていれば、その変更後の値を引き継ぎます。

## 保存と反映を確認する {#save-and-apply}

共通・サイト・板の通常の設定は、選択や入力に応じて保存されます。画面の保存状態と、各項目に表示される反映タイミングを確認してください。

| 表示の例 | 確認すること |
| --- | --- |
| この項目を個別に変更していないタブにも反映されます | 個別指定のない開いたタブが対象 |
| 次の更新から反映されます | 板・スレッドを次に更新したときの動作を確認する |
| 新しく開くスレッドから反映 | すでに開いているスレッドとの違いに注意する |
| 再起動後に反映 | アプリの再起動が必要 |

::: tip 保存方法は画面ごとに確認する
NGルールの編集など、「保存」ボタンで確定する画面もあります。「設定はすべて自動保存」とは考えず、その画面の操作に従ってください。
:::

## 変更が反映されないとき {#not-applied}

共通設定の項目の下に、現在のタブで使用しているサイト・板の設定や「このタブだけの設定」が表示される場合があります。

- **サイト・板の設定を使用している場合**：「個別設定を確認」から対象を確認し、必要なら上書きを解除します。
- **このタブだけの設定を使用している場合**：「この項目の個別設定を解除」で、その項目だけを上位の設定へ戻せます。
- **保存できなかった場合**：入力を確認し、「保存を再試行」を押します。
- **保存後の反映に失敗した場合**：保存失敗とは別に対象が表示されます。「反映を再試行」を押します。
