# カスタムCSS

設定画面やテーマ・レススキンの編集で足りない表示調整には、カスタムCSSを利用できます。まず[テーマ](themes.md)や[レススキン](response-skins.md)の項目で調整できるか確認します。

## ファイルと適用範囲 {#files}

| ファイル | 適用範囲 |
| --- | --- |
| プロファイルの `theme/main.css` | 共通の表示 |
| `theme/<テーマ名>.theme/user.css` | そのテーマを使用している画面 |

現在のプロファイルは[保存先とファイル構成](../reference/data-locations.md)から確認します。変更前に元のファイルを控え、UTF-8のCSSとして編集します。反映を確かめるため、保存後にSikiを再起動します。

## 対象を絞って変更する {#selectors}

サイトや板などの情報は、表示要素のクラスに含まれます。

| 接頭辞 | 例 |
| --- | --- |
| `st__` | `.st__2chan_net`：サイト |
| `sv__` | `.sv__may_2chan_net`：サーバー |
| `bd__` | `.bd__b`：板 |
| `th__` | スレッドのキー |

同じ板キーが別のサイトにもある場合は、板のクラスだけで対象を特定しないでください。実際の画面構造を開発者ツールなどで確認してから指定します。

例として、サイトと板の両方を絞って本文領域の背景色を変える場合は次のように記述します。

```css
.thread-item.st__2chan_net.bd__b {
  background-color: #eef4fa;
}
```

背景だけを変えると文字が読みにくくなる場合があります。使用するテーマの文字色や、狭い画面でも操作部品が見えるかを確認します。

## 旧版のCSSを移す {#migration}

インライン要素は `siki-thumb`、`siki-card`、`siki-movie`、`siki-anchor` などへ変更されています。動画周辺の親子構造も変わっているため、古いセレクターを無条件に流用しないでください。

スキンHTMLに直接JavaScriptや `onclick` を書いて実行する方法も利用できません。[旧バージョンから1.0.0へ](../migration/from-previous.md)を確認し、操作はコマンドの割り当てを使います。

## 表示が崩れたとき {#restore}

最後に追加したCSSを外して確認します。共通とテーマ別の両方を変更した場合は、一つずつ戻します。元へ戻せないときは、Sikiを終了して控えたファイルを戻し、再起動します。
