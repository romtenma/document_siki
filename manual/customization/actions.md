# クリック・ドラッグ・パネルの操作

Sikiではクリックや文字の選択、ドラッグ、パネル上のボタンへコマンドを割り当てられます。まず変更する操作と場所を決めます。

## 設定の入口 {#settings}

| 変えたい操作 | 開く分類・項目 |
| --- | --- |
| スレッド一覧のクリック・ダブルクリックなど | 板 → スレッドリストをクリックした時の挙動 |
| レス番号のクリック | スレッド → レス番号をクリックした時の挙動 |
| 文字を選択したときの操作 | スレッド → クイッククエリ |
| リンクやIDなどをドラッグしたときの操作 | マウス → スーパードラッグ |
| パネルに置く操作 | レイアウト → パネルのコマンド設定 |
| 中・第4・第5ボタン | マウス → 5ボタンマウス |

## 選択文字から操作する {#quick-query}

クイッククエリでは、テキストを選択したときに出すショートカットを設定します。検索やコピーなど、選択文字を渡す操作に使います。コマンドを選び、必要なパラメーターを確認して保存・適用します。

選択文字を外部サイトへ検索として渡す場合は、送信先とURLを確認します。選択範囲以外の情報も必要なコマンドは、場所によって実行できない場合があります。

## ドラッグ先に操作を割り当てる {#super-drag}

スーパードラッグを有効にし、設定で対象と操作を編集します。リンク、IDなどのドラッグ対象と、表示された操作の方向を確認して利用します。

板のスレッド一覧をマウスで選択できる設定が有効な場合、板に対するスーパードラッグは無効になります。ドラッグが選択として動く場合は、両方の設定を確認してください。

## パネルやマウスボタンへ置く {#panel-actions}

パネルのコマンド設定では、よく使う操作をパネルから実行できるようにします。実行コマンドだけでなく、表示するテキストなどの項目も確認します。

中ボタンの割り当ては、OSやSikiのオートスクロール機能と競合する場合があります。ボタン操作が動かないときは、割り当てとスクロール設定を合わせて調べます。

操作を自作する場合は[ユーザーコマンド](user-commands.md)、既存操作の名前とIDは[コマンド一覧](../reference/commands.md)を参照してください。
