# 板・スレッド内を検索する

今開いている内容を探す検索と、保存済みログを横断して探す検索があります。最初に探す対象を選びます。

## 目的に合う検索を選ぶ {#choose-search}

| 探したいもの | 使う検索 |
| --- | --- |
| 今の板にあるスレッドタイトル | 板内検索 |
| 今のスレッド内の単語 | スレッド内検索 |
| 過去に取得した複数のスレッドの内容 | [保存ログ検索](../features/log-search.md) |
| 設定項目の名前や説明 | 設定画面上部の「設定の検索」 |

保存ログ検索はインターネット上のすべての投稿を探す機能ではありません。サイトのスレッド検索ページを開く操作とも区別します。

## 表示中の内容を検索する {#current-content}

1. 検索したい板またはスレッドを選びます。
2. その領域の検索操作から検索欄を開きます。
3. 検索語を入力し、一致した位置や件数を確認します。
4. 次・前の結果へ移動する操作で、該当箇所を読みます。

検索とフィルターは役割が異なります。検索は一致箇所を探す操作、フィルターは表示対象を絞る操作です。検索モードを切り替えられる場合は、現在のモードを確認します。

検索欄の方式メニューでは「あいまい」「完全一致」「正規表現」を選べます。検索欄にいるときはEnterまたはF3で次へ、Shiftを組み合わせると前へ移動し、Escで閉じられます。

## 見つからない場合 {#no-match}

- 検索している対象が板かスレッドかを確認します。
- そのレスをまだ取得していない場合は、スレッドを更新します。
- 正規表現などのモードを使っている場合は、式や検索方法を確認します。
- 別のフィルター、NG・ミュート、ツリーの折りたたみも確認します。
- 別のスレッドにある内容なら、[保存ログ検索](../features/log-search.md)へ切り替えます。

キーボードやジェスチャーの割り当ては変更できます。検索を開く操作が分からない場合は、その領域の検索ボタンや、設定の割り当て一覧から確認してください。
