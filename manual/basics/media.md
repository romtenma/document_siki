# 画像・動画を見る

レス内の画像リンクやサムネイルから、ポップアップやビューアで画像を確認できます。開き方はクリック・マウスオーバーの割り当てや、サイトの対応状況で異なります。

## 画像を開く {#open-image}

1. レスのサムネイルや画像リンクを選びます。
2. ポップアップで確認するか、画像ビューアで開きます。
3. 詳しく見る場合は、1枚表示で全体・原寸を切り替えます。

リンク先が画像ファイルとは限らないため、通常のWebページはブラウザビューや外部ブラウザで開く場合もあります。

## ビューアの表示を選ぶ {#viewer}

| 操作 | 用途 |
| --- | --- |
| スレッド | スレッドの画像を確認する |
| 取得済み画像 | すでに取得した画像を条件から探す |
| 1枚表示 | 選んだ画像を大きく見る |
| 一覧表示 | サムネイルを並べて選ぶ |
| 画像情報 | URLや画像の情報を確認する |
| フィルムストリップ | 1枚表示の画像を切り替える |

取得済み画像の検索条件と、スレッドのフィルターは別です。表示対象が想定と違う場合は、ビューア上部の切り替えと条件を確認します。

## 保存・再読み込み {#save-reload}

ビューアの「保存」で表示中の画像を保存します。一覧で複数選択している場合は、その選択が保存対象になります。保存先は設定の「システム」→「ファイルの場所」などで確認します。

取得に失敗した場合は、エラーを確認し、再試行や「画像を再読み込み」を使います。[画像・動画の対処](../troubleshooting/media.md)も参照してください。

## 動画を確認する {#video}

動画は、対応する形式・サイトに応じてレス内や動画ビューアで表示します。再生ボタン、音量、シークなど、その表示場所の操作を使います。サイトのページや認証が必要な場合は、ブラウザでの操作になることもあります。

画像や動画を隠す設定については[NG・ミュート](../features/ng-and-mute.md)、表示範囲については[設定の適用範囲](../customization/settings.md)を確認してください。
