# スレッドを読む

板の一覧からスレッドを開き、レスを読めます。返信のつながりをたどる「ツリー」と、番号順に読む「時系列」を使い分けられます。

## スレッドを開く {#open-thread}

1. 読みたい板を開きます。
2. スレッド一覧からタイトルを選んで開きます。
3. スレッドの本文をスクロールして読み進めます。

開いたスレッドはタブとして残ります。別のスレッドを開いた後も、タブを選ぶと切り替えられます。板とスレッドの表示領域が狭いときは、画面上部のレイアウト操作から「単体／並列」を切り替えると、片方を広く表示できます。

## スレッドを更新する {#reload-thread}

スレッドの下部にある回転矢印の更新ボタンを押すと、新しいレスを取得します。ボタンの説明を確認し、板の一覧を更新するボタンと使い分けてください。

取得に失敗したときは、表示されたエラーを確認します。スレッドの更新と、サイトへの認証・書き込みは別の操作です。

## 既読・未読・新着を確認する {#read-state}

| 表示・用語 | 意味 |
| --- | --- |
| 既読 | 読んだ位置までのレス |
| 未読 | 取得済みのレスのうち、まだ読んでいない部分 |
| 新着 | 更新などで新しく取得したレス |
| ここまで読んだ | 読んだ位置を示す目印 |

未読と新着は同じ意味ではありません。読み残したレスがある状態で更新すると、以前の未読と今回の新着の両方がある場合があります。

読んだ位置や新着の位置へ移動する操作には「読んだ場所へ移動」「新着へ移動」があります。キーボードやマウスへの割り当ては利用者が変更できるため、自分の設定で操作名を確認してください。

## 時系列とツリーを使い分ける {#view-mode}

| 表示方法 | 向いている読み方 |
| --- | --- |
| 時系列 | レス番号の順に全体の流れを追う |
| ツリー | 返信元の近くに返信をまとめ、会話のつながりを追う |

![時系列では番号順、ツリーでは元のレスの下に返信をまとめる説明図](/images/thread-tree.svg)

*返信の並び方を示す説明図です。実際の画面はテーマやスキンによって異なります。*

全体の既定値を変えるには、設定の「スレッド」→「表示方法」→「スレッドの表示方法」を変更します。今開いているタブだけ変える操作は、コマンド名に「このタブだけ」と表示されます。

::: tip 変更する範囲を選ぶ
特定の板だけ、または今のタブだけ表示を変えたい場合は、[設定の適用範囲](../customization/settings.md#scope)を確認してください。
:::

## 返信ツリーを折りたたむ {#collapse-tree}

ツリー表示では、返信をつなぐ線を押すと、その枝を折りたためます。折りたたんだ部分には返信の件数が表示され、もう一度開くと内容を読めます。

折りたたみは返信のまとまりを一時的に閉じる操作です。内容を条件で非表示にする[NG・ミュート](../features/ng-and-mute.md)とは使い分けます。

## レスが見つからないとき {#missing-responses}

| 状況 | 確認すること |
| --- | --- |
| 画像や人気のレスだけが見える | スレッド上部のフィルターで絞り込んでいないか |
| 返信の件数だけが見える | ツリーの枝を折りたたんでいないか |
| NGやミュートの表示がある | [ルールやミュートの解除方法](../features/ng-and-mute.md#restore)を確認する |
| 表示方法を変えても反映されない | [サイト・板・タブの個別設定](../customization/settings.md#not-applied)を確認する |
