# 板を開く・スレッドを探す

板を開くと、その板にあるスレッドの一覧を表示できます。URLを直接開く方法と、BBSMenuの一覧から選ぶ方法があります。

## URLから開く {#open-url}

1. 板のURLをコピーします。
2. Siki上部のURL入力欄に貼り付け、移動します。
3. 板の名前とスレッド一覧が表示されたことを確認します。

[![Siki上部のURL入力欄にローカル板のURLを表示した例](/images/board-url.png)](/images/board-url.png)

*上部のURL入力欄へ、開きたい板のURLを入力します。画像はローカル板の例です。画面画像は選ぶと原寸で開けます。*

初めて扱うサイトでは登録の確認が表示される場合があります。対応する形式でないURLや、閲覧できないサイトは板として開けません。[対応サイト](../reference/supported-sites.md)を確認してください。

## BBSMenuから選ぶ {#bbsmenu}

1. 設定の「BBSMenu」で、利用する板一覧のURLを設定します。
2. 設定した一覧を更新します。
3. サイドパネルの「板一覧」（BBSMenu）を開き、分類や板を選びます。

[![左に板一覧のパネル、右にローカル板のスレッド一覧を表示した例](/images/board-list.png)](/images/board-list.png)

*左が「板一覧」の入口とパネル、右が開いた板のスレッド一覧です。画像は作業用のローカル板で、外部の板一覧はBBSMenuの設定後に選びます。*

BBSMenuの更新は板のリンク一覧の更新です。開いている板のスレッド一覧を更新する操作とは異なります。

## 一覧を更新・並び替えする {#list}

板の更新ボタンで現在のスレッド一覧を取得します。見たい列の見出しや並び替えメニューから、レス数・勢い・新着などの並びを選べます。

| 表示の例 | 読み方 |
| --- | --- |
| レス数 | スレッドにあるレスの数 |
| 未読 | 取得済みデータのうち、まだ読んでいないレス |
| 前回更新からの増加数 | 前の一覧取得と比べて増えたレス |
| 勢い | レスが付く速さの目安 |
| ★ | お気に入りに関係する表示 |

表示する列、並び順、サムネイル、優先表示は変更できます。個別指定した表示は、[共通設定](../customization/settings.md#scope)と異なる場合があります。

## スレッドを開く {#open-thread}

読みたいタイトルを選んで開きます。既存のタブを使うか、新しいタブに開くかは、操作や設定によって異なります。開いた後は[スレッドを読む](threads.md)へ進みます。

タイトルが見つからない場合は[板内検索](search.md#current-content)を使います。読み込めない場合は[通信・取得の対処](../troubleshooting/network.md)を確認してください。
